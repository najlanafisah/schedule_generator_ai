# Schedule Generator AI

A Flutter-based application designed to help users organize and generate schedules through a simple mobile interface.

## Features

- Schedule generation interface
- Schedule organization and display
- Date and time formatting
- HTTP support for API communication
- Environment variable configuration

## Tech Stack

- **Flutter**: Cross-platform application development
- **Dart**: Programming language
- **HTTP**: API requests
- **Flutter Dotenv**: Environment variable configuration
- **Intl**: Date and time formatting

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/schedule_generator_ai.git
   cd schedule_generator_ai
   ```

2. Install dependencies:

   ```bash
   flutter pub get
   ```

3. Configure the required environment variables in the `.env` file, if applicable.

4. Run the application:

   ```bash
   flutter run
   ```
